# Foresee — Demo

A prediction-exchange × talent-house demo (navy + gold). Static site, no build step.

- **`index.html`** — web homepage. 3 directions (A 看台 / B 交易 / C 对开), light/dark, 中/EN, working YES/NO bet loop. Bottom 📱 button opens the mobile app.
- **`mobile.html`** — mobile prototype (full P0 screens, KYC/2FA/USDT deposit-withdraw).

Open `index.html` in any static host. Photo slots accept drag-and-drop in the design tool; on a plain host they show branded placeholders.
